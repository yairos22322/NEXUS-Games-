# Security Policy

## Reporting a security issue

Please do not publish credentials, private keys, access tokens, or personal data in an issue.

If you discover a security problem in code from this repository, create a minimal report that explains the affected component and reproduction conditions without including real secrets.

## Scope

This project is a local Python/Panda3D game prototype. It should not require administrator access, browser credentials, crypto-wallet access, or unrelated personal files to run.
